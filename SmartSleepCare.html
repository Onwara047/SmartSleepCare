Google Apps Script Web App

URL จะถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้

BACKEND API
วิธีติดตั้ง: 1) เปิด script.google.com สร้าง New project 2) วางไฟล์ GAS ใน Code.gs 3) รัน setupSmartSleepCare() เพื่อสร้าง Google Sheets ใหม่และดู URL ใน Execution log 4) รัน seedDemoData() เพื่อเพิ่มข้อมูลสมมติ 30 รายการ 5) Deploy เป็น Web app และนำ URL /exec มาใส่ที่นี่
สำหรับการใช้งานจริง ให้รัน removeDemoData() เพื่อลบข้อมูลจำลอง และควบคุมสิทธิ์เข้าถึงข้อมูลสุขภาพตามนโยบายหน่วยงาน

โครงสร้างข้อมูลที่ระบบส่งไปยัง Google Sheets
